social

A private, single-user tool that publishes the owner’s own pre-edited short videos to the owner’s own channel.

Uses YouTube API Services

What it does

  • Once a day it uploads one finished video from the owner’s computer to the owner’s YouTube channel @prv60, with the title, description and tags the owner wrote.
  • It runs only on the owner’s own Windows PC. There is no server, no database and no public sign-up.
  • It has exactly one user: the channel owner.
