Privacy Policy

Last updated: November 19, 2026

1. YouTube API Services

“social” uses YouTube API Services to upload videos. By using it you agree to be bound by the YouTube Terms of Service. Google’s handling of your data is described in the Google Privacy Policy.

2. Who uses this tool

social is a personal tool. Its only user is the owner of the YouTube channel @prv60. It is not offered, sold or distributed to anyone else.

3. Information accessed, collected and stored

  • OAuth access token for the owner’s own Google account (scopes: youtube.upload, youtube.readonly). Stored only in a local file on the owner’s computer.
  • The owner’s own channel name (channels.list, mine=true) — read only to confirm which channel is connected; not stored.
  • The status and ID of videos the owner uploads (videos.insert / videos.list) — written to a local log file on the owner’s computer.

No information about any other YouTube user is accessed, collected or stored. No cookies, tracking, analytics or advertising are used.

4. How the information is used and shared

The information is used only to upload the owner’s videos to the owner’s channel and to record the result locally. It is not shared with, sold to, or disclosed to any third party, internal or external. Nothing is stored on any server.

5. Revoking access

Access can be revoked at any time from the Google security settings page: https://security.google.com/settings/security/permissions.

6. Data deletion

All stored data (the token and the local log) can be deleted at any time by deleting the local files, and is deleted automatically when access is revoked or the tool is uninstalled. Any data obtained from YouTube API Services is deleted or refreshed within 30 days, as required by the YouTube API Services policies. To request deletion or ask a question, contact the owner via the @prv60 YouTube channel.

7. Changes

Any change to this policy will be published on this page with a new “Last updated” date.
